2026-01-31 - Plan tab: stop repeated planner/target-selection cascade
----------------------------------------------------------------------
- Symptom: [planner], [prescription-query], [exercise-query], [workout-query], [target-selection] logs repeated in console when viewing Plan tab with no user action.
- Cause: useFocusEffect callback depended on loadTemplate, loadTodaySessionExercises, loadTodaySessions. loadTemplate is useCallback(..., [..., hasInitializedSelection]). When loadTemplate runs it calls setHasInitializedSelection(true), so loadTemplate gets a new reference. That recreated the useFocusEffect callback; React Navigation re-runs the effect when the callback identity changes, so loadTodaySessionExercises + loadTodaySessions ran again, causing repeated prescription/exercise/workout/target-selection queries and logs.
- Fix: Refs (loadTemplateRef, loadTodaySessionExercisesRef, loadTodaySessionsRef) hold the latest load callbacks; useFocusEffect reads from refs and no longer lists those callbacks in its dependency array. Effect now runs only on actual focus or when plannerNeedsRefetch/activeTemplateId/templateData/todayTemplateKeys/etc. change, not when loadTemplate identity changes.

2026-01-28 - Prescription rationale, research, and guidelines
-----------------------------------------------------------
- PRESCRIPTION_RATIONALE.md: New doc validating all prescription values against research, science, and biomechanics.
  - Definition: suggested_weight_multiplier_bw = working weight as fraction of BW (for prescribed rep range), not 1RM. Conversion from 1RM standards: working ≈ 70–80% 1RM for 8–12 reps.
  - Rep/set bands: 3×8–12 / 3–4×6–10 / 4–5×5–8 (beginner/intermediate/advanced) aligned with hypertrophy meta-analyses (3–5 sets, 5–30 reps effective).
  - Validated multipliers by category: compound barbell (Deadlift, Squat, Bench, OHP, Row, RDL, Hip Thrust), machine/cable (Leg Press, Lat Pulldown, Seated Cable Row), isolation (DB press/fly, lateral raise, curls, tricep, leg ext/curl, face pull), unilateral/bodyweight (BSS, lunge, calf; pull-up, push-up, etc. = 0).
  - Progression: weight = last + max(2.5% last, 2.5 lb); duration +5 s; research: 2–10% load increase when exceeding target (ACSM, NASM).
  - Guidelines for future exercises: how to derive multiplier (compare to similar movement, 1RM×0.7–0.8 for working), rep/set bands, checklist.
- ALGORITHMS.md: Added "Suggested weight and progression rationale" with formulas and link to PRESCRIPTION_RATIONALE.
- 00_INDEX.md: Added PRESCRIPTION_RATIONALE to core docs and "For Understanding Algorithms".

- ERR_INSUFFICIENT_RESOURCES: useFocusEffect ran loadTodayWorkout on every tab focus; loadTodayWorkout did N sequential getMergedExercise calls (one per exercise) plus auth, templates, session, etc. Rapid tab switching or repeated focus caused a request storm and exhausted browser resources.

FIXES (app/(tabs)/index.tsx):
- Batched exercise name resolution: Replaced per-exercise getMergedExercise loops with a single listMergedExercises(userId, exerciseIds) call for session exercises and for template slots. Build namesMap from the batch result so one failed request doesn't leave multiple "Unknown Exercise".
- In-flight guard: loadInFlightRef prevents overlapping loadTodayWorkout runs (e.g. focus + selectedPlanDayName effect). Set at start of loadTodayWorkout, cleared in finally.
- Focus throttle: useFocusEffect only calls loadTodayWorkout if last focus load was > 4s ago (lastFocusLoadRef). Prevents request storm when switching tabs repeatedly.
- Replaced console.log in useFocusEffect with devLog.
